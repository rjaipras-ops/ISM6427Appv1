# Meta agent notes

- One job per agent. If two agents keep overlapping, merge or split them.
- Record decisions in `knowledge/<agent>/decisions.md` as: date, decision, who decided, source.
- Never copy private emails, contracts, or copyrighted rule books into this public repo.
  Summarize, and say where the original lives (for example "owner's email from BeachesMLS, Nov 2026").
- After a review finds the same problem twice, add a check for it to the reviewer's checklist.
